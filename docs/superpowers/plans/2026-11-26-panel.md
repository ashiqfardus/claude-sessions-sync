# Browser Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `claude-sessions ui` opens a panel in the browser that does everything the CLI does, runs the CLI's own code, and is safe from every other website and program on the computer.

**Architecture:**
- **Pin, then refactor.** Golden tests pin every command's output. Then each `cmdX(args)` becomes flag parsing plus `runX(s streams, o xOpts) (xResult, error)`, which writes text to `s` and returns the result that `--json` prints.
- **`internal/panel`** knows nothing about commands. It holds the loopback server, the guard (Host, cookie, Origin, token, CSP), the one-time key, the redirect file and browser opener, the job runner with Server-Sent Events, the folder lister and the embedded static files.
- **`cmd/claude-sessions/ui*.go`** wires the panel to the commands:
  - an action table (`POST /api/run/<name>`) that calls the `runX` functions;
  - a read-only query layer (`GET /api/...`) built on `internal/...`;
  - the command map, which a test checks against the CLI.
- **The page** is hand-written HTML, CSS and ES modules, embedded. It is translated from the approved mockups, with IBM Plex embedded.

**Tech Stack:** Go 1.21 standard library (`net/http`, `embed`, `html/template`, `encoding/json`), plain HTML/CSS/JavaScript modules, IBM Plex woff2.

**Spec:** `docs/superpowers/specs/2026-11-25-panel-design.md`. Its "Decisions after review" and "Delivery" sections are binding. The mockups are the owner's private artifact named in the spec: `Main.dc.html` (Overview), `Conversations`, `Storage`, `Delete`, `Import`, `Settings`, `Combo` (the searchable dropdown), `Commands` (the command map), and the shared `panel.css`.
- Read them with the Artifact tool's `read` action, or from a local copy if the session has one.
- **Never commit them:** they are private, and this repository is public.
- Each `*.dc.html` is one screen's markup plus its state logic, in a design tool's templating (`{{...}}`, `sc-if`, `sc-for`, `dc-import`). Translate it; do not copy it.

This plan runs after `docs/superpowers/plans/2026-11-25-conversation-zips-and-prune.md` (Tasks 1-11) and names its interfaces as that plan defines them. See "Assumptions about the zips-and-prune plan" at the end.

## Global Constraints

- **Go and dependencies:** Go 1.21 minimum, standard library only. No Node, npm or build step. One binary. No `ServeMux` method patterns and no per-iteration loop variables (both are Go 1.22): copy a loop variable before a closure or goroutine captures it.
- **Before every commit:** `go test ./... && GOTOOLCHAIN=go1.21.13 go test ./...`. CI also runs `gofmt -l .` (must print nothing), `go vet ./...` and `go test -race ./...` on ubuntu, macos and windows.
- **The repository is public.** No real machine, user, project or employer names in code, tests, fixtures or docs. Use placeholders: `LAP-1`, `LAP-2`, `web-app`, `api`, `notes`, `you`.
- **Commits** go on `main` and are never pushed. Each message ends with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01PWT5vgdCpfR8xZ9xTkuWzN
  ```
- **CLI output is byte-identical** after every refactor task, except where a task names a deliberate change and updates its golden file in the same commit.
- **JSON:** new fields use the lowerCamelCase of the Go field name. Existing tags are kept.
- **Security values (spec):**
  - listen on `127.0.0.1` only;
  - `Host` must be `127.0.0.1:<port>` or `localhost:<port>`;
  - a 32-byte random one-time key, swapped for an `HttpOnly`, `SameSite=Strict` cookie;
  - every changing request is a POST with the cookie, a matching `Origin` and the per-run token header;
  - the key never appears in any process's arguments: the opener gets a 0600 redirect file, deleted after use.
- **CSP, exactly:**
  - panel: `default-src 'none'; script-src 'self'; style-src 'self'; font-src 'self'; img-src 'self' data:; connect-src 'self'; form-action 'none'; frame-ancestors 'none'; base-uri 'none'`;
  - conversation pages: `sandbox; default-src 'none'; style-src 'unsafe-inline'`.

  No inline `<script>`, no `style=` attribute, no `on*=` attribute. Dynamic sizes are set from JavaScript through `element.style`.
- **No request leaves the computer.** The fonts are IBM Plex Sans 400/500/600 and IBM Plex Mono 400/500, Latin1 woff2, embedded with the OFL text. The only external URL is the About link to the project's README.
- **Content from the archive is untrusted.** Titles, names, paths and log lines are set with `textContent` or `createTextNode`, never as HTML.
- **Times (spec):** heartbeat every 30 s. From the shortcut, the panel stops 10 minutes after the last heartbeat, never while a job runs. "Backing up normally" means a last backup within 2 hours.
- **Wording (spec):** "Compress old conversations", "Bring in work from another computer", "Never delete". Copy comes from the mockups. A changing action's report uses its button's word ("Delete 3 conversations", then "Deleted 3 conversations"). Raw errors are never shown.
- **Accessibility:** WCAG 2.2 AA, a visible focus ring, full keyboard use, the ARIA combobox and separator patterns, real `<button>`, `<a>` and `<label>` elements, and `prefers-reduced-motion` honoured in CSS and JS.

## Review Focus

1. **A computer with no archive folder yet** (the first-time user from `docs/setup-with-claude.md`).
   - Every screen shows "No archive folder yet. Choose the folder your sync app keeps in sync." with a Choose folder button.
   - Choosing a folder in the folder browser runs `config set-destination`.
   - No endpoint returns 500.

   Test: `TestPanelWorksWithNoArchive` (Task 14).
2. **A sync folder that streams files on demand.**
   - Overview, Conversations (without search text) and Storage read index files, names and `stat` only, never a transcript or zip.
   - A slow `/api/health` does not hold up the other endpoints.

   Test: `TestQueriesReadNoConversationFiles` (Task 14).
3. **The scheduled sweep holds the lock when the person clicks Back up now.** The job ends with "Another backup or import is running on this computer. Try again in a minute.", changes nothing, and leaves the sweep's lock alone. Test: `TestRunWhileSweepHoldsLock` (Task 16).
4. **Double clicks and two tabs.**
   - A second POST while a job runs gets 409 and starts nothing.
   - A reloaded tab re-attaches to the running job and sees its lines so far.

   Tests: `TestDoubleSubmitStartsOneJob` (Task 16) and `TestRunnerReplaysForLateSubscriber` (Task 11).
5. **Hostile text in the archive.** A title, machine name or path holding `<img src=x onerror=...>`, quotes or control characters:
   - shows as text everywhere;
   - a conversation page cannot run script;
   - `/read/` refuses `..`, encoded separators and links.

   Tests: `TestStaticNeverInjectsHTML` (Task 17) and `TestReadPageIsSandboxed` (Task 12).

### Task 1: Golden harness; pin the read-only commands

**Files:**
- Create: `internal/golden/golden.go`, `internal/golden/golden_test.go`
- Create: `cmd/claude-sessions/golden_test.go` (package `main_test`), `cmd/claude-sessions/testdata/golden/*.txt` (generated)

**Interfaces:**
- Produces (`internal/golden`, imported only by tests):
  - `func Normalize(s string, roots map[string]string) string`. The map is placeholder to path, such as `"<ARCHIVE>": dir`. In order:
    1. Replace every root, longest first, in each form: as given, its `filepath.EvalSymlinks` form (macOS `/private/var`), the `filepath.ToSlash` of both, and the JSON-escaped form (`\` doubled) of all of those.
    2. Replace `\r\n` with `\n`.
    3. Replace `\d{4}-\d\d-\d\d \d\d:\d\d:\d\d` with `<TIME>`.
    4. Replace every `\` with `/`. This is applied on every OS, so the files are the same on all three.
  - `func Check(t *testing.T, name, got string)` compares `got` with `testdata/golden/<name>.txt`. With `go test ... -update` it writes the file instead. On a mismatch, the failure names the first differing line, with 3 lines of context.
- Produces (`golden_test.go`):
  - `type goldenEnv struct{ m machine; home string; roots map[string]string }`.
  - `func goldenFixture(t *testing.T) goldenEnv` builds one machine and runs `config zip-sessions off` through the binary. The machine:
    - is `newMachine(t, "LAP-1", t.TempDir())`;
    - has a temp `home`;
    - has a git repo `web-app` (`gitRepo`) with two transcripts (`sessionLines`, fixed UUIDs), one subagent file and one tool-result file;
    - has a plain folder `notes` with one transcript;
    - has every file's modification time set by `pinTimes` to 2026-08-30T09:00:00Z.
  - `func pinTimes(t *testing.T, dirs ...string)`.
  - `func runGolden(t *testing.T, e goldenEnv, args ...string) string`.
    - It runs the binary with `--claude-dir` and `--archive` as `machine.run` does, with `HOME` and `USERPROFILE` set to `e.home`.
    - It captures stdout and stderr separately, normalizes both, and returns:
      ```
      $ claude-sessions <args, roots as placeholders>
      exit <code>
      --- stdout
      <stdout>
      --- stderr
      <stderr>
      ```
  - `type mask struct{ re, with string }`, applied after `Normalize`.

    - **Name:** the leaf. It is `Home folder` when a path equals a shard's `Home`. Two groups with the same leaf get the remote's host and path in brackets.
    - **Arg:** the first bucket's `Path`, which `matchProject` resolves to exactly this group.
    - **Order:** sorted by `Name`.
  - **The query:**
    ```go
    type convQuery struct {
        Text, Project, Machine, Age, State, Look, Role, Since, Until string
        CaseSensitive, Regexp, All                                  bool
        Limit, Page, Per                                            int
    }
    ```
    - `Machine` is "", a name, or `*many`.
    - `Age` is "", `7d`, `30d`, `over90d` or `over1y`.
    - `State` is "", `compressed`, `kept`, `forked` or `inuse`.
    - `Look` is `archive` (the default) or `local`.
    - `Limit` is the search match cap, 50 by default as the CLI's.
    - `Per` is 10 by default, at most 100.
  - **A row:** `type convRow struct{ ID, Title, Project, ProjectKey string; Buckets, Machines []string; Updated time.Time; Size, Full int64; Compressed, Kept, Forked, InUse, Readable bool }`.
  - **A page:** `type convPage struct{ Total, Page, Per, Pages, Unreadable int; TotalBytes int64; Stopped bool; Rows []convRow }`.
  - **`func queryConversations(root, dest string, q convQuery, now time.Time) (convPage, error)`. Rules:**
    - **Archive rows:**
      - one row per lower-cased ID across every machine's index;
      - IDs on the deleted list (not undone) are left out;
      - `Machines` are the machines whose index lists the ID;
      - `Updated` is the newest;
      - `Title` is the first prompt;
      - `Compressed` means a `<id>.conv.zip` is in one of its buckets (`convzip.Find`, once per bucket per request). `Size` is then the zip's file size and `Full` the index size;
      - `Forked` means `forks/<bucket>/<id>/` exists (one `ReadDir` of `forks/<bucket>` per bucket);
      - `Kept` is `kept(...)`;
      - `InUse` means this computer's local transcript for the ID changed within `archiveLag` (40 minutes);
      - `Readable` means the page exists (one `ReadDir` of `html/<bucket>` per bucket).
    - **Local rows** come from `runLs(quietStreams(), lsOpts{ClaudeDir: root})`, with `Machines = [machineName()]`.
    - **Text:** `runSearch(quietStreams(), ...)` with `Archived` set to `Look == "archive"`, and `Role`, `Regexp`, `CaseSensitive`, `All` and `Limit` as given. Only rows with a hit are kept. `Stopped` and `Unreadable` come from the search.
    - **Filters combine with AND.** `Project` compares `ProjectKey`. `Since` and `Until` are inclusive dates, read as `parseDate` reads them.
    - **Order and paging:** rows are sorted by `Updated`, newest first. A page out of range is clamped to the last one, and `Pages` is at least 1.
  - **Routes:**
    - `GET /api/projects` gives `[]projectOption`;
    - `GET /api/conversations` takes `q`, `project`, `machine`, `age`, `state`, `look`, `role`, `since`, `until`, `case`, `regexp`, `all`, `limit`, `page` and `per`. A bad value gives 400 with `{"error": <plain>}`.

    With no reachable archive, both answer 200 with `{"problem": "none"}` or `{"problem": "unreachable"}`, never an error. (`look=local` still works then.)

## Calls this plan makes (beyond the spec)

- **One job at a time, previews included.** A dry-run takes the lock as the CLI's does, so it cannot run beside a changing job anyway.
- **Every changing action goes through the runner, quick ones too, with `?wait=1`.** A rename during an import gets "Another action is running".
- **Stop during a job waits for the job.** The spec says Stop acts "at once" but also never cuts a job off; killing an import halfway is the worse outcome.
- **The cookie is `cs_panel_<port>`.** Cookies are not port-scoped, so two panels must not overwrite each other's cookie. A local server the person browses to on another 127.0.0.1 port also receives the cookie; that is accepted, since it needs the person's own browsing and a process already running on their computer.
- **One-time keys expire after 2 minutes unused.**
- **Progress is indeterminate,** with the latest log line, except for `clean`'s existing `n/m` counter. Commands print no new progress. The mockup's "Backing up 3 of 5" and "22 of 48" are not reproduced.
- **The activity list** shows this computer's log lines and each computer's `lastPush`. Panel jobs write one `UI:` line each, so imports and clean-ups appear. "Updated claude-sessions to X" is not shown, because nothing records it.
- **The Overview health uses `doctor` without the write probe,** so opening the page writes nothing to the archive.
- **`Config.SweepEvery`** records the interval install used, so Settings shows the real one.
- **The compression saving is estimated at 70%** of idle loose conversations, marked as a `shortcut:`.

## Spec gaps resolved

- **Sidebar width.** The spec says 180-360 px. The approved mockups and the brief fold to icons: `MIN 64`, folding below 140, default 200, `MAX 320`, Enter and a double click toggling. The mockups win.
- **`ui` itself has no entry on the exempt list.** `ui` maps to Settings, Stop the panel. Its launch options `--no-open`, `--port` and `--from-shortcut` are exempt, since they cannot be set from inside a running panel.
- **The parity test needs `--json` on every changing command.** `pull`, `restore`, `clean`, `prune`, `backup`, `config`, `install`, `uninstall` and `machines --forget` gain it. `--json` is already exempt from the command map.
- **`import --json` had no work folders.** Work rows are added (`kind: "work"`), and each row names its computer. This changes the JSON, and the CHANGELOG says so.
- **`--include-bare-name`'s approved label** ("Match a project by its folder name alone") describes matching, but the flag rewrites the folder name inside conversations. The label is kept, and a line saying what it does is added. **The owner should confirm the wording.**
- **`render --include` would be undone** by any computer that still has the project in its own exclusions. A `!pattern` line in `render-exclude.txt` makes it hold on every 0.7.0 computer.
- **`search --limit` and `ls --limit` had no drawn control.** `ls --limit` is the page size. `search --limit` is the "Stop after" combobox.
- **A second launch from a terminal** also reuses the running panel.
- **The command map is served** as `#/commands`, from the same table its test checks.
- **The Settings mockup has no Stop button.** The spec's Stop panel button goes in the About line, as "Stop the panel".
